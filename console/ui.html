Command Code Proxy · Console

需要管理口令

口令是启动 console 时的环境变量 CC_ADMIN_PASSWORD（在你启动 console 的那个终端里），至少 8 位，不落盘。 控制台的全部数据与操作都在它后面，读和写共用同一道闸门。 它同时用于加密池里的账号 key：换口令 = 旧账号解不开，忘了口令等于那些账号作废。
